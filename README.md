### Matthew Gruber

I make AI coding agents work in real environments, and I measure whether they did.

Before this, I was a Sergeant (E-5) in the US Army and the New Jersey Army National Guard, and
deployed to Kuwait from 2014 to 2015. After that I worked at J.P. Morgan, where I owned product
features end to end, and at Fiserv.

**What I build**

- [skill-harness](https://github.com/MrBinnacle/skill-harness): controlled experiments that run an
  agent with and without a skill, and report whether the skill helped, what it cost, and how sure
  we can be.
- [skills](https://github.com/MrBinnacle/skills): agent skills, each built from a problem I hit.
- [disconfirm](https://github.com/MrBinnacle/disconfirm): makes the agent find the cheapest test
  that could prove it wrong before it commits to a claim.
- [azimuth](https://github.com/MrBinnacle/azimuth): a skill that stress-tests go/no-go decisions.
  I froze it after a test I designed showed a newer model does the same work without it.

**Field notes:** I run Claude Code, Pi and T3 Code every day on Windows, and report what breaks
upstream.
